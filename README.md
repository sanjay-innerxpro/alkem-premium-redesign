# Alkem Laboratories — Premium Website Redesign Concept

An **independent, unofficial** front-end redesign concept inspired by https://www.alkemlabs.com/. It is intended as a design and development demo, **not** as an official or affiliated company website.

## What's included

- A responsive, modern pharmaceutical corporate homepage built with semantic HTML, CSS and vanilla JavaScript.
- Hero with medical/scientific capsule graphic, subtle orbital animation and editorial copy.
- Impact metrics, company story, four offerings, scientific research, interactive therapy tabs, global footprint, sustainability and careers.
- Working mobile navigation, keyboard-accessible therapy tabs, scroll reveal animations, count-up statistics and working links to official Alkem pages.
- Reduced-motion preferences, skip navigation and descriptive meta tags.
- No framework, paid dependency or build step required.

## Run locally

Open `index.html` in any modern browser, or use a static server:

```bash
python -m http.server 8080
```

Then visit http://localhost:8080.

## Host on GitHub Pages

1. Create a public repository, for example `alkem-redesign-concept`.
2. Upload `index.html`, `styles.css`, and `script.js` to the root.
3. Navigate to **Settings → Pages → Build and deployment → Deploy from a branch**, select `main` and `/ (root)`.
4. Open the published GitHub Pages URL.

## Customizing for your own company

Replace `ALKEM` and company copy with your business details, replace demonstration links with your site routes, and add your owned/licensed imagery. The concept ribbon and unofficial disclaimer must remain if using Alkem's name or other trademarks without permission. The two external company facility images are hotlinked to Alkem's official asset server strictly as references in this demo; **seek permission/license and host your own approved assets for any public or commercial use**. They have a CSS fallback if unavailable.

## Production readiness

This is a polished **single-page interactive prototype**, not a complete enterprise CMS. Before launching a corporate site add a CMS or backend, privacy/cookie policies, analytics consent, accessibility audit, SEO sitemaps, asset ownership validation, and proper legal/medical compliance review.
